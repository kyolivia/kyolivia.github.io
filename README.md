# olivia-tran.com

Plain HTML, no build step. Open `index.html` and it runs.

Page copy is in `renderVals()` at the bottom of `index.html`; experience entries are in the `experiences` array above it.

The handwriting is scanned images, not fonts. `assets/photos/title-leaf.jpg` doubles as the back of the contact page.

Deployed on GitHub Pages from `main`.
